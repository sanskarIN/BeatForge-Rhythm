# Security Policy

## Reporting

Please do not open a public issue for a vulnerability involving path traversal, unsafe import handling, data loss, or code execution. Contact `sanskarin@outlook.in` with reproduction steps and the affected commit.

## Scope

Imported chart, replay, and settings files are untrusted input. Report crashes, memory exhaustion, unsafe path handling, and bypasses of validation. Do not submit commercial audio or personal data in an issue.
