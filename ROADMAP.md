# Roadmap

- **v0.1 Foundation:** Godot C# project, clean boundaries, docs, sample chart, CI.
- **v0.2 Timing engine:** beat clock, BPM changes, configurable timing windows, calibration model. Audio-position synchronization, pause compensation, calibrated timestamp correction, and median-offset calibration are implemented.
- **v0.3 Playable rhythm system:** tap/hold surface, combo, score, practice controls. Tap, hold, slide, swipe, directional-swipe color coding, hold release checks, and lane-button press/release input are implemented.
- **v0.4 Song library:** search, sort, favorites, completion state, personal best. Core library state and menu display are implemented.
- **v0.5 Chart creation:** editor timeline, snapping, selection, undo/redo, validation, autosave.
- **v0.6 Campaign:** worlds, stages, objectives, stars, challenge conditions. Core catalog, persistence, and campaign browser are implemented.
- **v0.7 Replays/statistics:** replay JSON portability and persistent statistics are implemented; replay viewer and daily/weekly challenge history remain next.
- **v0.8 Accessibility:** persisted reduced effects, note sizing, large-button mode, vibration preference, and calibration history are implemented; device-specific haptic and text-scaling refinement remains next.
- **v0.9 Production testing:** device matrix, performance profiling, import fuzzing.
- **v1.0 Stable release:** Android packaging, signed builds, release checklist.
