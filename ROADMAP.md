# Roadmap

- **v0.1 Foundation:** Godot C# project, clean boundaries, docs, sample chart, CI.
- **v0.2 Timing engine:** beat clock, BPM changes, configurable timing windows, calibration model.
- **v0.3 Playable rhythm system:** tap/hold surface, combo, score, practice controls.
- **v0.4 Song library:** search, sort, favorites, completion state, personal best.
- **v0.5 Chart creation:** editor timeline, snapping, selection, undo/redo, validation, autosave.
- **v0.6 Campaign:** worlds, stages, objectives, stars, challenge conditions.
- **v0.7 Replays/statistics:** replay viewer, persistent stats, daily/weekly challenge history.
- **v0.8 Accessibility:** reduced effects, note sizing, contrast, haptics, text scaling.
- **v0.9 Production testing:** device matrix, performance profiling, import fuzzing.
- **v1.0 Stable release:** Android packaging, signed builds, release checklist.
